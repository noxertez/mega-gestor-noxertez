# Guía de Edición Visual para SahtoutCMS

Para editar tu página web de forma visual, sin necesidad de programar constantemente, te recomendamos las siguientes herramientas:

## 1. Panel de Administración (Interno)
Tu CMS ya viene con herramientas integradas para cambios básicos:
- **Logo y Redes Sociales:** Ve a `Admin Settings > General`.
- **Noticias:** En `Admin Panel > News` puedes añadir y editar contenido.
- **Tienda:** En `Admin Panel > Shop` gestionas los ítems y precios.

## 2. Edición de Imágenes y Diseño Gráfico
- **Canva ([canva.com](https://www.canva.com)):** La mejor opción para principiantes. Ideal para banners, fondos y logos.
- **Photopea ([photopea.com](https://www.photopea.com)):** Un clon de Photoshop gratuito que corre en el navegador. Úsalo para editar imágenes `.png` o `.jpg` que ya tienes en tu carpeta `img/`.

## 3. Editores de Diseño Web (Visuales)
- **Pinegrow Web Editor:** Permite abrir archivos PHP y editarlos visualmente mediante "drag and drop". Es excelente si quieres cambiar el layout sin escribir mucho código.
- **VS Code + Live Preview:** Si prefieres algo más técnico, instala la extensión "Live Preview" en VS Code para ver los cambios en tiempo real mientras editas.

## 4. Localización y Textos
Si quieres cambiar palabras específicas (como "Bienvenido" o nombres de botones), busca en la carpeta:
`c:\mis app de noxertez 2\SahtoutCMS-main\Sahtout\languages\`

Allí encontrarás los archivos de traducción para español, inglés, etc.
